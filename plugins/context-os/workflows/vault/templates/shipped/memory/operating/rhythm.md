# Rhythm

How this vault's operator thinks about time horizons, planning scope, and status.
Structural: changes rarely. What's actually being pursued right now lives in
`current-priorities.md`.

## Horizons

| Horizon   | Span    | Current period            |
| --------- | ------- | -------------------------- |
| **Macro** | Year    | <from_date> - <to_date>   |
| **Meso**  | Quarter | <from_date> - <to_date>   |
| **Micro** | Month   | <from_date> - <to_date>   |

Fallback default for `vault init quick`, kept only if the operator never runs the
full walkthrough. The full interview always replaces this with the operator's own
answers, regardless of whether they happen to match Macro/Meso/Micro, including
flattening to a single horizon or none at all.

Daily focus is captured in Obsidian daily notes, not here.

## Planning scope

_Run `/vault init` to record whether planning covers all entities together or each has its own rhythm._

## Status taxonomy

_Run `/vault init` to record the operator's labels for the state of an initiative (for example: active, parked, done, stalled)._
