# Templates

Reusable file templates. Obsidian Templater-compatible.

Any skill or script that generates one of the file types below must check for a matching file here before falling back to a built-in default. This directory always wins, the built-in fallback exists only for vaults scaffolded before a given template shipped, or where the operator has since deleted the file.

| File | Purpose |
| --- | --- |
| [daily-journal.md](daily-journal.md) | Daily note template. Use with Obsidian Templater. |
| [unique-note.md](unique-note.md) | Unique note template. Use with Obsidian Templater. |
| [wiki-article.md](wiki-article.md) | Compiled knowledge article, for `memory/wiki/`. |
| [raw-article.md](raw-article.md) | Processed source extract, for `memory/raw/`. |
| [research-article.md](research-article.md) | AI-discovered source, for `memory/research/`. |
| [distil-transcript.md](distil-transcript.md) | Distilled conversational transcript, for `memory/raw/`. |
| [insight-note.md](insight-note.md) | Atomic claim, for `memory/insights/`. |
| [entity-summary.md](entity-summary.md) | Entity overview, for `memory/entities/`. |
| [registry-agent.md](registry-agent.md) | Operator agent definition, for `registry/agents/`. |
| [registry-hat.md](registry-hat.md) | Task-phase hat definition, for `registry/hats/`. |
| [registry-prompt.md](registry-prompt.md) | Saved prompt, for `registry/prompts/<category>/`. |
| [registry-role.md](registry-role.md) | Cognitive-posture role definition, for `registry/roles/`. |
| [registry-skill.md](registry-skill.md) | Custom skill file, for `registry/skills/`. |
