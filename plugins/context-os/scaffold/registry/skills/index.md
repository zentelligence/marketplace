# Skills: Index

Custom skill files extending the vault's capabilities. Selected per session, not auto-activated.

| File | Skill | Purpose |
| --- | --- | --- |

## Adding a skill

Skill files follow the Claude Code SKILL.md format. Create `registry/skills/<slug>/SKILL.md` (or a flat `<slug>.md` if the skill is simple), then add a row to this index.

## Note: hats vs skills

Hats (cognitive task-phase lenses) live in `registry/hats/`, not here. This folder is for workflow and capability skills that extend what the vault can do. See [../hats/index.md](../hats/index.md).
