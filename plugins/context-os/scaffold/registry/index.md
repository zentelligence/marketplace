# Registry

Operator-curated reusable prompts, roles, hats, agents, and skills.

| Folder | Purpose |
| --- | --- |
| [prompts/](prompts/index.md) | Saved prompt templates. KERNEL+V framework and category sub-folders. |
| [roles/](roles/index.md) | Cognitive-posture definitions. Selected per session, not auto-activated. |
| [hats/](hats/index.md) | Task-phase lenses. Activated per task, released when the task is done. |
| [agents/](agents/index.md) | Operator agent definitions. Delegated to as sub-agents per task. |
| [skills/](skills/index.md) | Custom skill files extending vault capabilities. |

See [../memory/designs/prompts-roles-hats.md](../memory/designs/prompts-roles-hats.md) for the design rationale on how prompts, roles, and hats compose.
